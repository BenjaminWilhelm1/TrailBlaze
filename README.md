# TrailBlaze - Neon Endless Runner Game
Description

Trailblaze is a fast-paced, neon-themed endless runner game built with Phaser 3. Navigate through a constantly accelerating landscape, avoid obstacles, and experience dynamic weather effects that change based on your real-world location.

Features 

-  Endless Runner Gameplay: Test your reflexes with progressively increasing difficulty
-  Real-time Weather Integration: Uses OpenWeatherMap API to match in-game weather with your location
-  Dynamic Visuals: Vibrant neon aesthetic with unique weather effects (rain, fog, lightning)
-  Persistent High Scores: Compete with yourself by beating your previous best
-  Responsive Design: Play on both desktop and mobile devices
-  Audio System: Dynamic sound effects and background music

How to Play 

-   Avoid Obstacles: Jump over obstacles on the ground
-   Dodge Birds: Watch out for flying obstacles
-   Stayy Alive: The game gets faster over time - how long can you last?
-   Beat Your Score: Try to surpass your high score with each run

Controls

- Jump: Up Arrow
- Move Left/Right: Left/Right Arrow Keys
- Restart: Space Bar (after game over)

Weather API Integration 

The game uses the OpenWeatherMap API to fetch real-world weather data based on your geolocation. The in-game environment will change to reflect:

Clear Weather: Default blue night sky
Rain: Animated rain droplets
Fog: Misty overlay effect
Storm: Lightning effects with darker background
